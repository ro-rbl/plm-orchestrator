# plm-software

Plm pack: Code tasks, checked by running the examples in a sandbox.

A domain pack for [plm-core](https://github.com/ro-rbl/plm-orchestrator): install it with `plm packs install software`, which also pulls the
models it needs into Ollama. Documentation, benchmark results and caveats: https://github.com/ro-rbl/plm-orchestrator
