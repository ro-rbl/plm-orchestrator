# plm-cad

Plm pack: CAD parts as CadQuery programs, checked by building them with the OpenCascade kernel.

A domain pack for [plm-core](https://github.com/ro-rbl/plm-orchestrator): install it with `plm packs install cad`, which also pulls the
models it needs into Ollama. Documentation, benchmark results and caveats: https://github.com/ro-rbl/plm-orchestrator
