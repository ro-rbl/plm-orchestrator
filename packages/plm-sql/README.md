# plm-sql

Plm pack: SQLite queries, checked by running them on the schema given with the task.

A domain pack for [plm-core](https://github.com/ro-rbl/plm-orchestrator): install it with `plm packs install sql`, which also pulls the
models it needs into Ollama. Documentation, benchmark results and caveats: https://github.com/ro-rbl/plm-orchestrator
