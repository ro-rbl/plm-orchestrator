# plm-aerospace

Plm pack: Aerospace calculations, checked by units and sanity rules.

A domain pack for [plm-core](https://github.com/ro-rbl/plm-orchestrator): install it with `plm packs install aerospace`, which also pulls the
models it needs into Ollama. Documentation, benchmark results and caveats: https://github.com/ro-rbl/plm-orchestrator
